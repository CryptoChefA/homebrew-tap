# Homebrew tap for Pomofocus for Mac

```sh
brew install --cask cryptochefa/tap/pomofocus
```

[Pomofocus for Mac](https://cryptochefa.github.io/pomofocus-mac/) is a free, private Pomodoro and study timer for macOS 14 or later on Apple silicon. It isn't notarized by Apple yet; installing it this way opens it without the Open Anyway step. After that it updates itself, so `brew upgrade` isn't needed.

Source code: [CryptoChefA/pomofocus-mac](https://github.com/CryptoChefA/pomofocus-mac)
